# Security Policy

## Reporting a Vulnerability

Report suspected security issues privately to **security@gateway.fm**. Do not open public
issues or pull requests containing vulnerability reports or private audit findings.

Include the affected component and version, reproduction steps, impact and deployment
assumptions, and any suggested mitigation. Maintainers acknowledge and triage reports on a
best-effort basis, as described in the originating Open Privacy Suite security policy.

## Public Disclosure

Security issues should remain private until a fix or mitigation is available, unless
maintainers and the reporter agree on a different disclosure timeline.

## Scope and Release Status

This repository contains the Besu and Reth signed-approval integrations, their shared
protocol, build tooling and documentation. It does not currently provide an approved
production release or a separate security-support commitment.

CI checks public dependency advisories against the resolved versions and existing
version-bound reviews. A passing scan does not establish security or license clearance.
Repository publication and binary or image distribution require their respective approvals.
